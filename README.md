
# Password Strength Checker

A beginner-friendly Python command-line application that
evaluates password strength using basic character checks.

## Features

- Checks password length.
- Checks uppercase and lowercase letters.
- Checks digits and special characters.
- Provides suggestions to improve password strength.
- Includes automated unit tests.

## Requirements

- Python 3
- No third-party packages required

## Usage

Run the application:

```bash
python password_checker.py
```

Run the tests:

```bash
python -m unittest
```
